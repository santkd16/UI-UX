# Recycle Today, Protect Tomorrow — Australia × Colombia

Interactive intercultural English presentation for **three speakers**, organised into the **five sections** requested by the teacher.

**Repository:** https://github.com/santkd16/UI-UX  
**Web code:** [docs/index.html](./docs/index.html)  
**Expected GitHub Pages address, only after activation:** https://santkd16.github.io/UI-UX/

## What's included
- 1. Australia: Canberra map, population, Indigenous languages, food, culture, recycling technology.
- 2. Colombia: Bogotá map, population, native languages, food, plastic-pollution problem.
- 3. Percentages and sources: Australia / Colombia figures with a **methodology warning** (they are *not directly comparable*).
- 4. Organizations: DCCEEW, APCO, Clean Up Australia, MinAmbiente, SuperServicios and recyclers.
- 5. Campaign: slogan, digital poster, classroom action plan, **First & Second Conditionals**, vocabulary, QR, official video.
- Live English podcast script for three students, with past perfect and other grammar.
- Presentation mode: click **▶ Present**, then use **left/right arrows**, **space**, **Esc** or the buttons.
- Podcast recording: audio is stored **on the presenter's computer only** and downloaded as WebM.
- Public internet content: image gallery uses Wikimedia Commons MediaWiki API (no API key), maps use OpenStreetMap, a real UNEP video uses a YouTube embed, QR uses api.qrserver.com. Attribution and sources are included on the page.

## ONE REQUIRED GITHUB ACTION — Enable Pages
The website was uploaded successfully, but GitHub Pages is **not enabled** on this repository. The initial automated deploy failed at *Configure GitHub Pages* because the Pages site did not exist. The connected GitHub app does not offer the repository administration operation needed to enable it.

1. Sign in to the repository and visit **https://github.com/santkd16/UI-UX/settings/pages**.
2. In **Build and deployment → Source**, choose **GitHub Actions** and save.
3. Go to **Actions → Deploy English presentation to GitHub Pages**.
4. Click **Run workflow → Run workflow** (or commit a change to any file in docs/).
5. After the run succeeds, open **https://santkd16.github.io/UI-UX/**.

If GitHub Pages is already enabled later, every subsequent change to docs/ publishes automatically.

## Accuracy note
Australia's **67%** (2024–25) is a national resource-recovery measure across multiple waste streams, including energy recovery. Colombia's approximately **20%** (2024) refers to ordinary waste recovered in its public cleaning-service reporting. They are displayed together as *contextual indicators*, with a prominent warning that they are not like-for-like percentages.
